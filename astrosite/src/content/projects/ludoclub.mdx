At **Moonfrog Labs**, I worked as a **Game Developer (SE 2)** on *Ludo Club*, a massively popular real-time multiplayer Ludo game.  
My contributions included:

- **Engine Migration**: Migrated the game from **Cocos2d-x** to **Unity3D** and refactored the core loop logic using a **Finite State Machine** design pattern.  
- **Feature Development**: Built multiple features such as achievements and rewards, across both **server-side (Node.js)** and **client-side (C#)**.  
- **Tooling Support**: Developed functionality for administrative and developer tools to assist CSM and QA teams.  
- **Live Ops**: Deployed and monitored server releases in production, and actively supported live operations, bug fixes, and feature updates.  

This project strengthened my expertise in **scalable gameplay systems, server-client features, and production support** for a large-scale multiplayer title.
