  <p>
    Umbra Engine is a custom C++ game engine designed for 2D games, featuring a lightweight 
    Entity-Component-System (ECS) architecture, modular event handling, and support for 
    real-time game mechanics.
  </p>


  <h2>Features</h2>
  <ul>
    <li>Custom ECS framework inspired by ENTT.</li>
    <li>Event system using <code>std::function</code> for flexible observers.</li>
    <li>Collision and physics management for 2D gameplay.</li>
    <li>Support for SFML integration and rendering pipeline.</li>
    <li>Memory-safe entity management with optional smart pointers.</li>
    <li>Finite State Machine support for game states.</li>
    <li>Virtual file system for mounting directories or .pak files.</li>
  </ul>
