A first person melee combat inspired by games like Dark Mesiah and Kings Field.
Made in Unreal 5.5, Uses Gameplay Ability System and State Tree for the bread and butter of the logic.
Enemies run indivisual logic in thier respective state tree and a combined manager sends events to co-ordinate and balance the flow of combat.
