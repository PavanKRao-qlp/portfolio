At **Dream Game Studios**, I worked as a **Senior Gameplay Programmer** on *Dream Cricket*, an AAA mobile cricket title.

<Image src={gameplay} alt="gameplay" />
My contributions included:

- **Character Systems**: Architected core character control systems — networked character behaviours, responsive batting and fielding mechanics, and synchronised player controls with **client-side prediction and server reconciliation**.
- **Feature Ownership**: Delivered 5 major gameplay features end-to-end — **Async Multiplayer, Player Card Gacha, Team Management, Inventory System, and Emote Celebration** — each owned from design handoff through production release.
- **Game Modes**: Designed a unified game mode architecture enabling seamless PvP/PvE across **Quick Match, Tournaments, and Private Lobby** with consistent performance across distributed environments.
- **Design Tooling**: Built real-time parameter tuning tools and gameplay visualisation overlays, shortening the feedback loop between design intent and player-facing results.
- **Engineering Quality**: Introduced **MVCS-like frontend architecture**, mentored junior engineers on code quality practices, and established **CI/CD build automation via Jenkins**.
