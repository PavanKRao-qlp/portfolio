At **Dream Game Studios**, I worked as a **Senior Gameplay Programmer** on *Dream Cricket*.  

<Image src={gameplay} alt="gameplay" />
My contributions included:

- **Core Gameplay**: Built batting mechanics, integrated cutscenes, and helped develop multiple game modes such as Blitz Mode, Tournaments, and Private Lobby.  
- **Game Tools**: Created tools to help design teams fine-tune and visualize gameplay parameters.  
- **Frontend Systems**: Implemented the frontend architecture using an **MVCS-like pattern**, optimizing load times and enabling rapid integration of UI components.  
- **Metagame Features**: Developed features like player inventory and lineups to enhance player progression and engagement.
